Quero que você redesenhe e melhore completamente a interface de um aplicativo mobile chamado “MetaSense”, mantendo a proposta e as funcionalidades descritas abaixo, mas deixando o resultado muito mais profissional, moderno, consistente e pronto para uma apresentação de projeto tecnológico.

IMPORTANTE:
Não tenho como te enviar o design original. Portanto, use SOMENTE a descrição abaixo como referência e crie uma nova versão visual baseada nela.

## OBJETIVO DO APLICATIVO

O MetaSense é um aplicativo de monitoramento ambiental e qualidade do ar. Ele ajuda o usuário a acompanhar dados ambientais da sua região, visualizar informações em um mapa, receber alertas e acompanhar o impacto ambiental.

A interface deve transmitir:
- tecnologia
- sustentabilidade
- confiança
- inovação
- facilidade de uso
- monitoramento em tempo real
- visual profissional de startup/empresa de tecnologia

Não quero que pareça um aplicativo genérico ou um template pronto.

## IDENTIDADE VISUAL

Utilize principalmente:
- azul escuro como cor principal
- azul/ciano para informações e elementos interativos
- verde para indicadores positivos e sustentabilidade
- amarelo/laranja para atenção
- vermelho para alertas críticos
- branco ou tons muito claros para áreas de conteúdo

O design precisa ter alto contraste e excelente legibilidade.

Use uma tipografia moderna e limpa, semelhante a Inter, Poppins ou outra fonte sans-serif profissional.

Crie uma identidade visual consistente em TODAS as telas.

Use:
- bordas arredondadas
- cards modernos
- sombras muito sutis
- ícones consistentes
- espaçamento generoso
- hierarquia visual clara
- componentes reutilizáveis

Evite excesso de elementos, excesso de cores, textos pequenos e aparência poluída.

# MELHORIAS IMPORTANTES

Não simplesmente reproduza as telas.

QUERO QUE VOCÊ MELHORE O DESIGN.

### 1. CONSISTÊNCIA

Todas as telas devem parecer parte do mesmo aplicativo.

Utilizar:
- mesma tipografia
- mesmos raios de borda
- mesmos ícones
- mesmo sistema de cores
- mesmos espaçamentos
- mesmos estilos de botão
- mesmos cards

### 2. HIERARQUIA

O usuário precisa saber imediatamente:
1. onde está
2. qual é a informação mais importante
3. o que precisa fazer
4. quais informações são secundárias

### 3. PROFISSIONALISMO

O resultado deve parecer um aplicativo desenvolvido por uma equipe profissional de UX/UI.

Não utilizar:
- excesso de gradientes
- excesso de sombras
- elementos aleatórios
- emojis em excesso
- fontes diferentes
- cards desnecessários
- textos muito pequenos

### 4. ACESSIBILIDADE

Garantir:
- contraste adequado
- botões grandes o suficiente
- textos legíveis
- ícones acompanhados de texto quando necessário
- informações importantes não dependentes apenas de cores

### 5. RESPONSIVIDADE

O projeto deve ser pensado para smartphone.

Utilizar uma estrutura semelhante a:
390 × 844 px.

Os elementos devem se adaptar a diferentes tamanhos de tela.

### 6. UX

Criar uma experiência intuitiva.

O usuário deve conseguir chegar às funções principais em poucos toques.

A navegação inferior deve permanecer consistente entre:
Home
Mapa
Alertas
Impacto
Perfil.
